# Mixy Shop — Avatar Assets

Place the following image files in this `assets/` folder:

- **male.png** — Male avatar image (e.g., 200x200px)
- **female.png** — Female avatar image (e.g., 200x200px)

You can use any avatar images you prefer. Free avatar packs are available at:
- https://www.flaticon.com/free-icons/avatar
- https://ui-avatars.com/

Recommended size: 200×200px, PNG format with transparent background.
